# Simulated Macrocystis weight data

A small simulated dataset of harvested plants, for runnable examples. It
shares sites and years with the other simulated *Macrocystis* datasets;
some site-years have no weight data.

## Usage

``` r
data_weight_sim_macro
```

## Format

A data frame with the columns of
[`kb_check_data_weight_macro()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_check_data_weight_macro.md).
