# Simulated Nereocystis wet/dry data

A small simulated dataset of tissue samples, for runnable examples.

## Usage

``` r
data_wetdry_sim_nereo
```

## Format

A data frame with the columns of
[`kb_check_data_wetdry_nereo()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_check_data_wetdry_nereo.md).
