# Simulated Macrocystis canopy data

A small simulated dataset of canopy maps, for runnable examples.

## Usage

``` r
data_survey_canopy_sim_macro
```

## Format

A data frame with the columns of
[`kb_check_data_survey_canopy()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_check_data_survey_canopy.md)
and `region`, a factor to pool by.
