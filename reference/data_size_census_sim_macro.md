# Simulated Macrocystis size census data

A small simulated dataset of every plant counted by the surveys in
[data_survey_in_situ_sim_macro](https://hakaiinstitute.github.io/kelpbio/reference/data_survey_in_situ_sim_macro.md),
for runnable examples.

## Usage

``` r
data_size_census_sim_macro
```

## Format

A data frame with the columns of
[`kb_check_data_size_census_macro()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_check_data_size_census_macro.md).
