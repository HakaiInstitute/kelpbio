# Example Nereocystis weight fit

A fit of
[`kb_fit_weight_nereo()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_fit_weight_nereo.md)
to
[data_weight_sim_nereo](https://hakaiinstitute.github.io/kelpbio/reference/data_weight_sim_nereo.md)
with fewer draws than the default, for exploring the fit methods without
running the sampler.

## Usage

``` r
fit_weight_sim_nereo
```

## Format

An object of class
`c("kb_fit_weight_nereo", "kb_fit_weight", "kb_fit")`.
