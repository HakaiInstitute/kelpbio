# Example Macrocystis carbon fit

A fit of
[`kb_fit_carbon_macro()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_fit_carbon_macro.md)
to
[data_carbon_sim_macro](https://hakaiinstitute.github.io/kelpbio/reference/data_carbon_sim_macro.md)
with fewer draws than the default, for exploring the fit methods without
running the sampler.

## Usage

``` r
fit_carbon_sim_macro
```

## Format

An object of class
`c("kb_fit_carbon_macro", "kb_fit_carbon", "kb_fit")`.
