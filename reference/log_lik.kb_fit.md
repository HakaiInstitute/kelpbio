# Pointwise Log-Likelihood

The pointwise log-likelihood of the observed data (from the Stan
generated quantities), suitable for
[`loo::loo()`](https://mc-stan.org/loo/reference/loo.html).

## Usage

``` r
# S3 method for class 'kb_fit'
log_lik(object, ...)
```

## Arguments

- object:

  A `kb_fit` object.

- ...:

  Unused.

## Value

A draws-by-observations (`D x N`) matrix.
