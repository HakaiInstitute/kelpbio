# Simulated Nereocystis size sample data

A small simulated dataset of measured plants, for runnable examples. It
shares sites and years with the other simulated *Nereocystis* datasets;
some site-years have no size data.

## Usage

``` r
data_size_sample_sim_nereo
```

## Format

A data frame with the columns of
[`kb_check_data_size_sample_nereo()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_check_data_size_sample_nereo.md).
