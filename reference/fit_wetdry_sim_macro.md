# Example Macrocystis wet/dry fit

A fit of
[`kb_fit_wetdry_macro()`](https://hakaiinstitute.github.io/kelpbio/reference/kb_fit_wetdry_macro.md)
to
[data_wetdry_sim_macro](https://hakaiinstitute.github.io/kelpbio/reference/data_wetdry_sim_macro.md)
with fewer draws than the default, for exploring the fit methods without
running the sampler.

## Usage

``` r
fit_wetdry_sim_macro
```

## Format

An object of class
`c("kb_fit_wetdry_macro", "kb_fit_wetdry", "kb_fit")`.
